# 🌸 日和記帳 (Hiyori Book)

> 一款秉持簡約日系美學（Minimalist Japanese Design）的現代響應式收支記帳網頁程式。  
> 採用低飽和淡藍與紫灰和色調，前後端完整分離架構，支援多裝置資料雲端持久化保存。

---

## 📸 設計特點與 UI 佈局 (遵循需求規格)

1. **簡約日系風格 (Japanese Minimalist Aesthetic)**
   - **主色調**：薄花淡藍 (`#7392B7`) 與 藤鼠紫灰 (`#7D788B`)。
   - **調色盤**：全站採用低飽和度的日系和色（撫子紅、青瓷綠、琥珀金、雲藍、淺草青）。
   - **排版與質感**：結合日本 Zen Maru Gothic 與 Noto Sans TC 字體、圓潤留白、柔和擴散陰影與卡片邊框。
2. **主要介面元素配置**：
   - 👤 **登出入鍵 (右上角)**：顯示會員登入/註冊入口，登入後展示頭像、暱稱、即時預算狀態膠囊與登出鍵。
   - 📅 **固定日曆 (中央偏上，固定位置不動)**：
     - 固定於畫面中央偏上區域，隨瀏覽保持穩定位置。
     - 預設選取當前日期，可左右切換月份或點選「今日」快速跳轉。
     - 支援收支標記點（紅點代表支出、綠點代表收入）。
     - 日曆正下方呈現「選取日期的收支明細卡片」，可快速查閱、編輯與刪除當日所有紀錄。
   - ➕ **記帳區域 (畫面右下角的 + 號，彈窗顯示)**：
     - 右下角常駐和風漸層圓形懸浮按鈕（FAB）。
     - 點擊後以**優雅彈窗**呈現記帳介面。
     - 支援收支切換、大字體金額輸入、預設代入日曆所選日期、日式圖示分類按鈕、自訂分類標籤、常用金額快捷鍵 (+50, +100, +200, +500, +1000) 及支付方式。
   - 📊 **消費統計報表 (畫面左下角的按鈕，彈窗顯示)**：
     - 左下角常駐日系膠囊統計報表按鈕。
     - 點擊後以**全功能彈窗**呈現視覺化報表。
     - 包含篩選列（本月/上月/近30天/今年/分類/類型/搜尋關鍵字）、KPI 收支結餘卡、預算進度與超支警告、各分類收支圓餅圖、近半年消費趨勢折線圖、明細表格及 CSV 匯出功能。

## 🛠️ 核心功能列表

### 1. 會員管理與帳號安全 (Member Management & Security)
- **嚴謹表單驗證與合理範圍**：
  - 帳號檢查：必填，長度需介於 3 至 20 個字元，僅允許英數字母、底線或中文字。
  - 密碼檢查：必填，長度需介於 6 至 50 個字元。
  - 註冊與重設時支援「確認密碼」防呆比對，暱稱長度上限 20 字。
  - 前後端均提供友善的即時成功/失敗通知（日系風格 Toast 與彈窗內警示）。
- **「忘記密碼」處理機制**：
  - 登入介面提供「忘記密碼？」入口，一鍵切換至「重設密碼」介面。
  - 輸入使用者帳號與新密碼後，後端透過加鹽重新雜湊更新至資料庫。
  - 重設成功時自動清除該帳號舊有 Session，並發行新憑證立即安全自動登入。
- **資料庫實際建立與驗證**：
  - 帳號與密碼雜湊實際存儲於資料庫（`backend/data/db.json`）。
  - 密碼採用 Web Crypto API 加鹽 SHA-256 安全雜湊，絕不儲存明文。
- **狀態持久化 (重新整理 / 登出再登入)**：
  - 頁面載入時透過 Token 自動驗證（`/api/auth/me`），重新整理頁面仍能自動復原登入狀態與當前選取日紀錄。
  - 登出時立即吊銷 Token 並重設畫面。
  - 再次登入同帳號時，後端即時自資料庫讀取該使用者的完整歷史記帳、預算與圖表數據。
- **不同會員的私人資料嚴格隔離 (Multi-tenant Isolation)**：
  - 每筆紀錄、預算與統計均綁定唯一 `userId`。
  - 後端 API 嚴格校驗憑證，會員之間絕對無法查看、修改或刪除他人的收支紀錄。
- **示範體驗**：登入彈窗提供「**一鍵帶入 Demo 帳號**」功能（帳號：`demo` / 密碼：`password123`），內建豐富的當月與過往記帳紀錄、圖表數據與預算設定。

### 2. 記帳核心功能 (Accounting Core)
- **欄位完整**：金額、收支類型 (支出 / 收入)、日期 (YYYY-MM-DD)、分類標籤、項目備註、支付帳戶 (現金/信用卡/LINE Pay/悠遊卡/銀行轉帳)。
- **日系和風分類**：
  - 支出分類：🍱 餐飲飲食、🚌 日常交通、🏠 居家生活、🍵 休閒娛樂、🛍️ 購物消費、💊 醫療健康、📚 學習成長、🍃 其他支出。
  - 收入分類：💼 薪水收入、🧧 獎金紅利、📈 投資理財、✨ 副業收入、🌸 其他收入。
  - 支援「**自訂分類標籤**」輸入。
- **預算設定與超支警告**：
  - 支援設定每月支出預算上限（預設 NT$ 20,000）與超支警戒門檻（預設 80%）。
  - **即時預算進度條**：動態展示已用預算比例，隨狀態自動變換色彩（正常青瓷綠 → 80% 警戒琥珀金 → 超支 100% 玫瑰紅）。
  - **超支警示通知**：當新增支出導致超支或接近預算門檻時，前端會即時跳出警示 Toast 與報表中的超支警示橫幅。

### 3. 消費統計報表 (Analytics & Reports)
- **總收入支出清單**：總覽所選統計區間的總支出、總收入、結餘淨額與交易筆數。
- **各分類收支圓餅圖 (Donut Chart)**：
  - 原生 SVG 輕量圖表，免載入龐大外部 CDN，色彩採用日系和色。
  - 支援在「支出分類」與「收入分類」之間隨時切換。
  - 具備滑鼠 Hover 懸停高亮、即時切換中間圓心總金額與佔比。
  - 右側/下方附帶詳細圖例清單（包含各分類金額與百分比）。
- **月消費折線圖 (Monthly Trend Line Chart)**：
  - 繪製近 6 個月的收入與支出走勢曲線，帶半透明漸層色彩填滿。
  - 支援數據節點 Hover 顯示該月詳細數值。
- **多維度篩選功能**：
  - 區間篩選：本月、上月、近 30 天、今年。
  - 類型篩選：全部收支、僅看支出、僅看收入。
  - 分類篩選：動態下拉選單過濾特定分類。
  - 關鍵字搜尋：即時搜尋備註、分類或支付方式。
- **數據匯出**：支援一鍵將篩選後的收支清單匯出為標準 UTF-8 CSV 檔。

### 4. 前後端分離與跨裝置保存 (Architecture & Persistence)
- **架構分離**：
  - **後端 (Backend)**：採用高效 TypeScript + Deno，提供完整的 RESTful API 與靜態資源託管。
  - **前端 (Frontend)**：純原生的 HTML5 / CSS3 (CSS Variables + RWD Flexbox/Grid) / Vanilla Modern JavaScript，無臃腫外部依賴，速度極致飛快。
- **跨裝置雲端資料庫保存**：
  - 資料庫持久化存儲於 `backend/data/db.json`，支援原子化寫入防止損壞。
  - 任何裝置（電腦瀏覽器、手機 Safari/Chrome、平板）只要透過網路連線至伺服器並登入相同帳號，所有記帳、預算與統計數據皆即時同步一致。

### 5. 響應式網頁設計 (RWD)
- **手機 (< 640px)**：
  - 日曆縮放適配觸控螢幕。
  - 右下角與左下角懸浮按鈕尺寸符合單手拇指操作。
  - 記帳與統計報表彈窗自動轉化為滑順的「**底部抽屜 (Bottom Sheet)**」。
  - 圓餅圖與圖例改為垂直堆疊排列，閱讀清晰。
- **平板 (641px ~ 1024px) 與 電腦桌面 (> 1024px)**：
  - 居中日系雅緻版型，固定日曆搭配半透明磨砂玻璃背板，層次分明。

## 🧰 使用技術 (Tech Stack)

本專案堅持極簡、輕量、高效的現代 Web 架構，**無臃腫外部依賴套件與 CDN 庫**：

### 前端 (Frontend)
- **核心語言**：標準純原生 HTML5、CSS3、Vanilla JavaScript (ES6+)。
- **樣式架構**：
  - CSS 自訂屬性 (CSS Variables) 打造日系和色主題系統。
  - Flexbox 與 CSS Grid 混合排版，支援 RWD 多螢幕響應式（電腦、平板、手機）。
  - iOS Safari 專屬優化（防雙擊自動縮放 `font-size: 16px`、安全區域 `env(safe-area-inset-top)` 避讓、數字鍵盤 `inputmode="numeric"`）。
- **圖表視覺化**：原生 SVG 動態繪製各分類收支圓餅圖（Donut Chart）與近半年月消費趨勢折線圖（Line Chart），免載入 Chart.js 等大型第三方庫。
- **字型資源**：Google Fonts（Zen Maru Gothic、Noto Sans TC）。

### 後端 (Backend)
- **執行環境**：[Deno](https://deno.com/) 2.x（基於 V8 引擎與 Rust 開發的新一代現代 JavaScript/TypeScript 執行環境）。
- **語言**：TypeScript（強型別安全檢查與介面約束）。
- **HTTP 伺服器**：原生 `Deno.serve()` 提供高效 RESTful API 路由與靜態資源託管。
- **身分驗證與安全**：
  - 密碼加密：使用原生 Web Crypto API (`crypto.subtle.digest("SHA-256")`) 進行加鹽雜湊（Salted Hash）。
  - Token 機制：使用 `crypto.getRandomValues()` 生成 256-bit 高強度隨機 Session Token。

---

## 🗄️ 資料庫 (Database)

- **資料庫形式**：JSON 文件資料庫（輕量、高透明度、易於備份與跨平台轉移）。
- **實體檔案路徑**：`backend/data/db.json`
- **資料持久化機制**：
  - **原子化寫入 (Atomic Write)**：寫入時先產出暫存檔 (`db.json.tmp.<timestamp>`)，完成後再原子重命名替換，防止意外斷電或併發寫入損壞資料。
  - **併發控制鎖 (Promise Lock Chain)**：內建非同步防併發互斥鎖，確保頻繁讀寫時資料一致性。
- **主要資料集合 (Collections)**：
  1. `users`：會員資料表（帳號 ID、使用者名稱、顯示暱稱、密碼加鹽雜湊值、鹽值 Salt、每月預算設定與超支警戒門檻、註冊時間）。
  2. `records`：記帳明細表（紀錄 ID、綁定 `userId`、收支類型 `expense/income`、金額、交易日期、分類標籤、項目備註、支付帳戶、建立/修改時間）。
  3. `sessions`：登入憑證表（Session Token、綁定 `userId`、建立時間、到期時間）。
- **多租戶隔離**：所有收支資料嚴格綁定唯一 `userId`，跨裝置登入時僅能檢視與修改個人資料。

## 🚀 執行方式 (How to Run)

### 前置環境需求
電腦需安裝 **[Deno](https://deno.com/)**（Deno 2.x 以上版本）：
- Windows 安裝指令 (PowerShell)：`irm https://deno.land/install.ps1 | iex`
- macOS / Linux 安裝指令：`curl -fsSL https://deno.land/install.sh | sh`

---

### 啟動伺服器

#### 方式一：Windows 一鍵批次檔（最簡單）
直接雙擊專案目錄下的：
```bash
start.bat
```
*(伺服器會自動於後台啟動，並為您彈出瀏覽器連線)*

#### 方式二：PowerShell 專屬腳本
對著專案根目錄下的 **`start.ps1`** 點擊滑鼠右鍵 ➔ 選擇 **「用 PowerShell 執行」**。

#### 方式三：命令列手動執行
在專案根目錄開啟終端機（CMD / PowerShell / Bash），輸入：
```bash
deno task start
```
或直接輸入完整指令：
```bash
deno run -A backend/server.ts
```

---

### 開啟網頁與跨裝置瀏覽

- **💻 本機電腦瀏覽**：
  在電腦瀏覽器網址列輸入：
  👉 **http://localhost:8000**

- **📱 跨裝置瀏覽 (手機、平板或其他電腦)**：
  1. 請確保手機/平板與執行伺服器的電腦連線在 **同一個 Wi-Fi 區域網路** 或 **手機個人熱點**。
  2. 電腦啟動伺服器時，視窗會提示目前的 IP 位址（例如 `10.99.253.56` 或 iPhone 熱點 `172.20.10.2`）。
  3. 在手機瀏覽器（Safari / Chrome）網址列直接輸入：
     👉 **`http://<您的電腦IP>:8000`**  *(例如：`http://172.20.10.2:8000`)*
  4. ※ 溫馨提醒：若手機連不上，請以系統管理員身分執行專案目錄下的 `allow_firewall.bat` 放行 Windows 防火牆 8000 連接埠。
